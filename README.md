# Git Version Control Demonstration

This repository demonstrates Git version control operations such as
creating repositories, committing changes, branching, merging, and pushing code to GitHub.

---

## Objectives
- Learn Git basics
- Track changes using commits
- Work with branches
- Merge code safely
- Push project to GitHub

---

## Tools Used
- Git
- Git Bash (Windows)
- GitHub

---

## Conclusion
This project demonstrates the practical usage of Git for version control
and collaboration in software development.
